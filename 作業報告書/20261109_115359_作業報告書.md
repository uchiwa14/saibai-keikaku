## フォルダとGitの初期化
1. ユーザーから栽培計画フォルダを開く依頼があり、現在のワークスペースが対象フォルダであることを確認した。Windows エクスプローラーでもフォルダを開いた。
2. Git 初期化の依頼を受けて状態を確認したところ、Git リポジトリではなく、フォルダ内にファイルもなかった。
3. `git init` を実行し、空の Git リポジトリを作成した。

## VS Code SkillのOneDrive共有
1. 複数の VS Code ワークスペースで個人共通利用する Skill の場所を案内した。Copilot の個人 Skill の標準パスは `%USERPROFILE%\.copilot\skills`。
2. Skill を OneDrive 上の `VS_ Copilot\skills` に置き、各 PC で標準パスからジャンクションで接続する方法を案内した。
3. `VS_ Copilot\connect-copilot-skills.bat` を作成した。バッチは自身のあるフォルダの `skills` を接続先にし、ローカルに既存の実フォルダがある場合は日時付きバックアップへ移してからジャンクションを作成する。既存のリンクがある場合は変更せず終了する。
4. 一時プロファイルを使ったテストでジャンクション作成と接続先を確認した。
5. ユーザーの実行依頼を受け、バッチをこの PC で実行した。ローカルの空フォルダは `%USERPROFILE%\.copilot\skills.backup-<日時>` に移動され、`%USERPROFILE%\.copilot\skills` が OneDrive の `VS_ Copilot\skills` を指すことを確認した。
